# ToxiFlag - Decisions

- D1: Virtual environment at .venv inside the project (Python 3.13.15, Windows).
- D2: Day 1 installs only data/ML basics. torch and transformers come later.
- D3: Machine has 7.4 GB RAM, GPU not yet checked. Plan: baseline locally, transformer fine-tuning on a free Colab GPU unless a local CUDA GPU is found.
- D4: data/raw, data/processed and models/ are git-ignored (size and dataset licenses).
- D5: Rejected Kaggle hinglish_cyberbullying_dataset_25000.csv as a research dataset: only 40 unique texts among 25,000 rows (24,960 exact duplicates), so any split leaks. Not used for training or evaluation.
- D6: Rejected Hinglish_CodeMixed_Data.csv (9,354 rows, labels -1/0) as a primary dataset: in a 30-sample check per class, every label-0 text was a voice-assistant command (timer/alarm/traffic) and label -1 texts were profanity-containing chat, so the label is confounded with source/domain. Several label -1 texts use profanity as filler, so -1 does not mean toxic. 1,152 duplicates after lower/trim. Sorted by label. Source page, license and label definition not verified.
- D7: Bohra et al. dataset (GitHub repo deepanshu1995/HateSpeech-Hindi-English-Code-Mixed-Social-Media-Text) contains only tweet IDs and labels (4114 lines in id_annotated.tsv; paper reports 4575 tweets); tweet text must be requested from the authors per README. Repo license is GPL-3.0 (data reuse terms to be confirmed). Not usable until text is obtained. Tweet re-hydration rejected as unreliable.
- D7: Bohra et al. dataset (GitHub repo deepanshu1995/HateSpeech-Hindi-English-Code-Mixed-Social-Media-Text) contains only tweet IDs and labels (4114 lines in id_annotated.tsv; paper reports 4575 tweets); tweet text must be requested from the authors per README. Repo license is GPL-3.0 (data reuse terms to be confirmed). Not usable until text is obtained. Tweet re-hydration rejected as unreliable.
- D8: Primary dataset = source 'hate_speech_tsv' subset (4,574 Roman-script Hinglish tweets; 2,914 Normal / 1,660 Hate) from the combined PRISM Kaggle file; class counts match Bohra et al. (2018) within 1 row, provenance not independently verified, redistribution permission to be confirmed with the authors. Excluded: english_dataset, hindi_dataset (100% Devanagari), profanity_list (single words), and LLM-relabeled files (about 50% of Hinglish labels flipped, not ground truth). Labels are Hate vs Normal Speech, not toxicity; label noise observed in a 40-sample read.
- D9: Dataset license (Kaggle compilation): CC BY-SA 4.0. Cite Bohra et al. (2018) and the Kaggle dataset; data/ stays git-ignored; any shared processed splits must use the same license.
- D10: Near-duplicate key = lowercase text with URLs, mentions, punctuation and spaces removed. 3 conflicting-label groups (6 rows) dropped; 19 same-label near-duplicates collapsed. 4,574 -> 4,549 rows.
- D11: clean_text replaces URLs with URL and @mentions with @user and collapses whitespace; keeps case, punctuation, negations, slang and emojis. Raw text kept. Lowercasing happens inside model pipelines; spelling normalization is a later, separate experiment.
- D12: Stratified 70/15/15 split, random_state=42: train 3,184 / val 682 / test 683. Test set untouched until final evaluation; thresholds tuned on val only.
- D13: Baseline = TF-IDF (word 1-2 grams or char_wb 2-5 grams, lowercase, sublinear tf, min_df=2) + Logistic Regression (class_weight=balanced). Features and C chosen on validation macro-F1 only; test evaluated once. Bootstrap 95% CI reported because the test set has 683 rows.
- D14: Baseline analysis shows labels in this dataset are strongly keyword/topic driven ('hate' pushes towards Hate; rape/terrorism/murder towards Normal). Task framing to be decided: hate speech detection on Hinglish tweets, not general toxicity.
- D15: Transformer = google/muril-base-cased fine-tuned on Colab T4 with a plain PyTorch loop (transformers 5.18.0, torch 2.11.0). max_length 128 (99.97% of train tweets fit; mean 31.8 tokens), lr 2e-5, batch 16, 4 epochs, class-weighted CE, fp16. Best epoch chosen on validation macro-F1; test evaluated once. Val/test probabilities saved for the disagreement phase.
